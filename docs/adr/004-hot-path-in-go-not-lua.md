# ADR-004：热路径（移动/AOI/攻击）留 Go，不进 Lua —— 容量支柱

状态：已采纳 ｜ 日期：2026-11-22

## 背景
Lua VM 单解释器 = 单线程脚本执行，是唯一真容量瓶颈。纯 Lua 承载全部消息时单区瓶颈约 800 在线；目标 3000。

## 决策
**每秒 ≥5 包/玩家的高频路径在 Go 实现**：移动/位置同步、AOI 广播、攻击/受击路由、帧编解码、定时器节拍。
低频交互路径（任务/奖励/活动/商城/GM）进 Lua——对齐原版 C++ 分工（C++ 处理移动广播，Lua 只管业务）。
边界清单维护在 engine-api.md §四；新增路径先归类再实现。

## 后果
+ 单区 3000 在线（gopher-lua 即可），换 LuaJIT 后到 8000
- 移动/AOI 需在 Go 侧重建（原版这部分逻辑在 C++ 黑盒里，需 Ghidra 辅助+实测校准）
- 边界判断成为日常开发纪律（CI 无法全自动判定，靠 review）
