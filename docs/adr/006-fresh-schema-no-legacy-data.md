# ADR-006：全新数据库 schema，不做旧数据迁移

状态：已采纳 ｜ 日期：2026-11-22

## 背景
www/backup/database 的 dump 是空结构+静态配置（players/actors/feecallback 全 0 行），无历史玩家数据。旧玩家持久化 blob（actorbinarydata/actorvariable）是 C++ 私有序列化格式，逆向成本 1-2 周。

## 决策
Go 版自定义 schema（贴原版表名语义但不逐字段照抄），不做旧档兼容。blob 格式逆向降为"仅在确需读旧档时再立项"。

## 理由
1. 无数据可迁——兼容旧格式没有收益
2. schema 自由度打开：JSON 列存 Lua 表序列化等现代方案可选
3. 省 1-2 周逆向工期

## 后果
+ 阶段 0.4 从"必须逆向"降为"可选调研"
- 2021 年线上老玩家数据彻底弃用（本就无档，确认无损）
- 若将来拿到真实旧档需要迁移，再立逆向专项
