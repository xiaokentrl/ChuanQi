# ADR-005：首版跨服降级为 stub

状态：已采纳 ｜ 日期：2026-11-22

## 背景
原版含跨服协议（csproto 60 条命令）、跨服连接栈（csbase/crossnet）、s999 跨服区、合服机制（lianfu）。完整实现预估 2-3 周。

## 决策
首版（M0-M6）跨服相关只做 **stub**：csmsgdispatcher 注册表接通但消息返回"功能维护中"；跨服连接不建立；合服工具不做。完整实现为独立的阶段 6。

## 理由
1. 单区全玩法跑通是主线，跨服是锦上添花
2. 跨服涉及多进程协同状态，过早实现会在接口未稳时返工
3. Lua 层跨服代码（csmsgdispatcher 等）无需改动，Go 侧 stub 不破坏加载链

## 后果
+ 主线工期省 2-3 周
- 跨服玩法（跨服BOSS/3v3/巅峰赛）首版不可用——Lua 里对应活动需在活动配置关闭
- 触发条件：单区全玩法验收（M6 后）→ 启动阶段 6
