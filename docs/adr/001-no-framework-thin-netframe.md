# ADR-001：不用重量级框架，自建 netframe 薄层

状态：已采纳 ｜ 日期：2026-11-22

## 背景
Go 重写需要网络层（TCP/WS、会话、包编解码）。候选：游戏框架（leaf/nano/pitaya）、网络库（gnet）、Web 框架（gin/echo）、纯标准库。

## 决策
标准库 + 精选库，自建 `internal/netframe` 薄层（帧编解码/会话/对拍钩子，数百行量级）。总直接依赖 ≤8。

## 理由
1. 本工程质量锚点是**逐字节对拍**——框架抽象把字节藏起来，对拍变难
2. 难点在 Lua 契约与战斗数学，框架不覆盖
3. 架构已被原版钉死（无发挥空间）；Go netpoller 下 8192 会话是平凡问题
4. gin/echo 类别错误：核心链路无 HTTP JSON

## 后果
+ 字节级完全可控，对拍直通
+ 依赖面最小，维护负担低
- 自建代码需自己负责边界（用 golden 测试补）
