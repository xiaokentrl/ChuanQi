# ADR-003：服务配置 .txt 复用 Lua 引擎解析

状态：已采纳 ｜ 日期：2026-11-22

## 背景
四个服务的配置（DBServer.txt 等）是 Lua 表语法（含注释），原版由 C++ 内嵌 Lua 加载。

## 决策
Go 服务启动时用 gopher-lua 直接执行配置文件取表，不写独立解析器。

## 理由
1. 零兼容风险：配置语法 = Lua 语法（含 `--` 注释、嵌套表）
2. 配置若有条件逻辑（#if OSTYPE 已被预处理层处理）也能兼容
3. 一个依赖两用（宿主已引入）

## 后果
+ 免维护解析器
- 配置加载依赖 luahost 初始化顺序——cmd 装配时注意先后
